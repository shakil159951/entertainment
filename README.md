✨ Key Features
Automated Daily Updates: Runs automatically every 24 hours via GitHub Actions, with on-demand manual trigger support.

Multi-Source Aggregation: Combines selected external M3U playlists and optional local entries into a single playlist.m3u.

Clean Titles & Original Logos: Formats titles and categories cleanly while keeping original poster/logo URLs unchanged and free of extra redirect/backlink injection.

Smart Deduplication: Keeps the highest available quality version when duplicate movie titles appear.

▶️ How to Use
Copy the raw playlist.m3u link above.

Paste it into your IPTV/VOD player, Android/Android TV app, or web player that supports remote M3U playlists.

🛠️ Manual Workflow Trigger
Go to the Actions tab in this repository, select Auto Update VOD Playlist, and click Run workflow to generate an immediate update.
